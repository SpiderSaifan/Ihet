Ihet Translator Guide


Hello! This is the guide to set up the Ihet Translator.



Step 1:

First, you need to download the Ihet .ttf file. This is the file that tells your computer the Ihet language. You can download it here.

Step 2:

After you download the .ttf file, you need to install it. To install the .ttf file,
you have to right-click it and click "Install":


Step 3:

After the .ttf file is installed on your computer, launch the IhetSetup.exe file
that you should have downloaded when you were in the main page.
If you haven't downloaded it, go back to the main page and download it:

Step 4:

When you launch the setup, go through the setup.
When you have finished the setup, press the "Finish" button to complete the Ihet Translator setup:

Step 5 (final step):

If you wish to run the program afterwards,
navigate to the directory where you've downloaded it, and run the "Ihet Translator" file:


Congrats! You've just installed the Ihet Translator!
